# 🛍️ NEXUS CATÁLOGO — VITRINE PÚBLICA

Vitrine pública do **Nexus Catálogo**, criada para apresentar anúncios de produtos e serviços de forma simples e acessível pelo celular ou computador.

A vitrine permite que visitantes consultem os anúncios publicados e acessem diretamente as informações disponibilizadas pelos anunciantes.

## 🌐 Acesso

**Vitrine pública:**

https://ia-termux.web.app

**Criar anúncio:**

https://nexus-catalogo.onrender.com/

## ✨ Recursos

- 🛍️ Visualização dos anúncios publicados
- 🔎 Consulta de produtos e serviços
- 📱 Interface adaptada para dispositivos móveis
- ➕ Botão para criação de novos anúncios
- 📤 Compartilhamento dos anúncios
- 💚 Compartilhamento pelo WhatsApp
- 🤖 Acesso ao Meta AI
- 🌙 Modo escuro
- ▦ Modo de visualização dos anúncios
- 🔏 Acesso aos Termos, Política de Privacidade e informações sobre o desenvolvimento
- 📱 Navegação otimizada para celular

## 🔏 Termos, Privacidade e Desenvolvimento

## 📢 Sobre os anúncios

Os anúncios publicados na vitrine podem apresentar:

- Nome do produto ou serviço
- Código do anúncio
- Descrição
- Preço
- Imagens
- Vídeo, quando disponível
- Informações de contato
- Condição do produto
- Informações sobre entrega e pagamento, quando cadastradas

Cada anunciante é responsável pelas informações, imagens, preços, produtos, serviços e demais conteúdos apresentados em seu anúncio.
